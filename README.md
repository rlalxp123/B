# 🥚 포켓몬 알 키우기 (다마고치)

포켓몬 알을 키우는 모바일 다마고치 웹게임이에요. 알에서 누가 태어날지, 마지막에 무엇으로 진화할지 모두 랜덤이에요!

- 🌌 코스모그 → 코스모움 → **솔가레오 ☀️ / 루나아라 🌙**
- 🔥 파이리 → 리자드 → 리자몽 → **메가리자몽X 💙 / 메가리자몽Y 🔥** (메가진화)
- 🥋 배루키 → **시라소몬 🦵 / 홍수몬 🥊 / 카포에라 🌀** (3개 중 랜덤)
- 🦊 이브이 → **샤미드 / 쥬피썬더 / 부스터 / 에브이 / 블래키 / 리피아 / 글레이시아 / 님피아** (8개 중 랜덤) 빌드 과정 없이 `public/index.html` 하나로 동작하고, Cloudflare에 바로 배포할 수 있어요.
- 👊 리오르 → 루카리오 → **메가루카리오 🔵** (메가진화)
- 🌱 이상해씨 → 이상해풀 → 이상해꽃 → **메가이상해꽃 🌺** (메가진화)
- ⚡ 피츄 → 피카츄 → **라이츄 ⚡**
- 💧 꼬부기 → 어니부기 → 거북왕 → **메가거북왕 💦** (메가진화)
- 📘 그 밖에 도감 1~155번 포켓몬 133마리도 모두 나와요 (캐터피, 구구, 고오스, 잉어킹, 잠만보, 미뇽, 치코리타 등). 진화 계열을 따라 자라고, 한 단계뿐인 포켓몬은 다 자란 모습으로 태어나요

## 게임 방법
- 🥚 **알 디자인도 랜덤**: 줄무늬·물결·지그재그·다이아·무지개·불꽃·물결·번개 같은 큰 무늬 위에 땡땡이·얼룩·반짝이·하트·소용돌이·별·나뭇잎·사탕 무늬를 랜덤으로 겹치고, 색과 각도도 매번 달라져서 알이 매번 새로워요. 가끔 밤하늘 알, 아주 가끔 반짝이는 ✨황금 알도 나와요
- ⭐ **전설의 포켓몬**: 1% 확률로 알에서 전설의 포켓몬 15마리(가이오가, 그란돈, 레쿠쟈, 루기아, 칠색조, 라티아스, 라티오스, 뮤, 뮤츠, 라이코, 앤테이, 스이쿤, 프리져, 썬더, 파이어) 중 하나가 태어나요
- ✨ **이로치**: 알이 부화할 때 5% 확률로 색이 특이한 이로치 포켓몬이 태어나요. 진화해도 이로치 그대로예요 (도감에는 표시되지 않아요)
- 🥚 **알**: 따뜻하게 🔥 / 쓰다듬기 🤗 / 노래하기 🎵 로 부화 게이지를 채우면 여러 포켓몬 중 하나가 랜덤으로 태어나요 (가만히 둬도 천천히 차요). 노래하기는 부화를 도와주고, 알이 깨어나기 직전에 알 속 친구의 힌트가 나와요
- 🍬 밥주기 · ⭐ 놀기(별 잡기 미니게임 10초) · 🫧 씻기기 · 🌙 재우기 · 🤗 쓰다듬기(펫을 직접 눌러도 돼요) · 💊 약주기(상태가 아주 나쁠 때)
- 배부름·기분·청결·체력이 모두 괜찮으면 시간이 지날수록 진화 게이지가 차요. 돌봐줄 때마다 더 빨리 차요
- 진화 게이지가 가득 차면 진화! 마지막 진화는 솔가레오/루나아라, 메가리자몽X/Y, 시라소몬/홍수몬/카포에라, 브이즈 8마리 중 하나가 랜덤
- 최종 진화 후에는 ✨ 전용 기술(메테오드라이브 / 섀도레이 / 플레어드라이브 / 블래스트번 / 무릎차기 / 메가톤펀치 / 트리플킥 / 하이드로펌프 / 10만볼트 등)을 쓸 수 있고, 📖 도감에서 새 알을 받아 다른 친구도 모을 수 있어요
- 이름표를 누르면 이름을 지어줄 수 있어요
- 📜 **키운 기록**: 새 알을 받거나 처음부터 시작하면 지금까지 키운 친구가 기록에 남아요 (진화해 온 길, 함께한 날짜와 시간, 친밀도, 이로치·황금 알 표시). 지금 키우는 친구도 맨 위에 보여요
- 진행 상황은 폰에 자동 저장되고, 앱을 닫아둔 시간(최대 8시간)도 반영돼요

예전 뮤츠 동굴 게임은 `/mewtwo/` 주소에 그대로 있어요.

## Cloudflare에 배포하기

### 방법 1: 대시보드에서 GitHub 연결 (가장 쉬움, 폰으로도 가능)
1. https://dash.cloudflare.com → **Workers & Pages** → **Create** → **Import a repository**
2. 이 GitHub 레포를 선택
3. 빌드 명령은 비워두고, 배포 명령은 `npx wrangler deploy` (기본값) 그대로 두기
4. 배포가 끝나면 `https://cosmog-tamagotchi.<계정>.workers.dev` 주소로 플레이

이후 이 브랜치에 푸시할 때마다 자동으로 다시 배포돼요.

### 방법 2: 내 컴퓨터에서 명령어로
```bash
npm install
npx wrangler login
npm run deploy
```

로컬 테스트: `npm run dev` → http://localhost:8787
