# 🌀 뮤츠 동굴찾아가기

뮤츠를 미로 끝의 동굴까지 데려다 주는 웹게임이에요. 빌드 과정 없이 `public/index.html` 하나로 동작하고, Cloudflare에 바로 배포할 수 있어요.

## 게임 방법
- 이동: 방향키 / WASD / 화면 드래그(스와이프) / 화면 아래 방향 버튼(누르고 있으면 계속 이동)
- 🌀 사이코키네시스: 바라보는 쪽으로 최대 3칸 날아가 바위 🪨나 적을 맞혀요 (스페이스바 · 화면 탭 · 버튼). PP를 1 써요
- 구슬 🔮: 모으면 PP가 1 늘고, 많이 모을수록 별을 더 받아요 (전부 모으면 ★★★)
- 적 포켓몬: 부딪히면 HP가 1 줄어요 (HP 3)
  - 꼬마돌: 느리게 돌아다녀요 · 딱구리: 데굴데굴 직진해요 · 기술을 2번 맞혀야 쓰러져요
  - 롱스톤: 몸이 길고 바위를 통과해요 · 기술을 2번 맞혀야 쓰러져요
  - 아르세우스: 가까이 오면 쫓아와요 · 쓰러뜨릴 수 없고 기술로 4초 동안 멈출 수 있어요
- 💡 힌트: 동굴까지 가는 길을 2.5초 보여줘요 (레벨마다 3번)
- 레벨이 오를수록 미로가 커지고 바위가 많아져요

## Cloudflare에 배포하기

### 방법 1: 대시보드에서 GitHub 연결 (가장 쉬움, 폰으로도 가능)
1. https://dash.cloudflare.com → **Workers & Pages** → **Create** → **Import a repository**
2. 이 GitHub 레포를 선택
3. 빌드 명령은 비워두고, 배포 명령은 `npx wrangler deploy` (기본값) 그대로 두기
4. 배포가 끝나면 `https://mewtwo-cave.<계정>.workers.dev` 주소로 플레이

이후 이 브랜치에 푸시할 때마다 자동으로 다시 배포돼요.

### 방법 2: 내 컴퓨터에서 명령어로
```bash
npm install
npx wrangler login
npm run deploy
```

로컬 테스트: `npm run dev` → http://localhost:8787
